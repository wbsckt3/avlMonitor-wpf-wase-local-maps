En qué consiste

Georreferencia y haz seguimiento de móviles donde ya trabajas: desde tu base de datos SQL Server

No es un SaaS de mapa en el navegador: es un cliente Windows sobre tu SQL Server, con Waze embebido. Compra y licencia en el panel P2L; operación diaria en tu escritorio.

Cómo se activa la licencia en local

Al crear la empresa, el panel genera una clave de licencia. Con el ID y el backend P2L, esa clave activa AvlMonitor en tu PC mediante un archivo .env.

🔑 Clave solo al crear la empresa

P2L_COMPANY_KEY se muestra una sola vez. P2L_COMPANY_ID queda siempre visible en tu cuenta.

💬 WhatsApp → panel → .env

Nos contactas, creas la empresa, obtienes el ZIP según tu paquete y configuras el .env con ID, clave y P2L_BACKEND_BASE.

✅ Validación contra P2L

Al abrir AvlMonitor, valida la licencia con el backend. Si ID y clave son correctos, queda activo en local.
